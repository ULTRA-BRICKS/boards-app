Original outlines. Real variation.

This is an experimental original typeface, not a renamed commercial font. It has two continuous axes: weight 300–800 and width 85–125, Latin and Cyrillic. The source drawings and compiler are included in this repository. The button constructs a TrueType font on your device, without sending text or drawings to a service.

The specimen is a separate application, build and deployment from Boards. It does not load workspace data or require sign-in.
