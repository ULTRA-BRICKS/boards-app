# Прерывания: сверка с результатами процессов, 16 сентября 2026

## Подтверждённые события, а не одна общая причина
- Два последних полных ревью (`review-morning-0916`, `review-completion-0916`) завершились **с ошибкой через 305 секунд**. В одном роль correctness вернула `TRUE-SILENCE TIMEOUT after 300s`; другие роли успели вернуть замечания. Это таймаут ревьюера, не доказательство таймера ChatGPT.
- До этого три полных ревью завершались через **223, 230 и 244 секунды**. `exit 0` означает выполненный запрос ревью, а не отсутствие замечаний. Их найденные дефекты учитывались отдельно.
- Самый первый staged diff превысил предел 300 000 байт. Ограниченный просмотр не был принят за полное ревью. Последующие вызовы передавали весь diff через документированный лимит размера.
- После потери ответа удалённый процесс может завершиться. Поэтому очередной `go` не должен порождать ещё один такой же процесс. Сначала читаются его терминальный JSON и лог.
- На текущем замере Mac сообщил 50% свободной памяти, один процесс Claude и два Bun. Признаков исчерпания памяти именно в этот момент нет. Этот снимок не устанавливает причину прежних сбоев.
- Для сегодняшнего нового браузерного теста инструмент вернул явную защитную блокировку. Файл не создан; тест не пересылался другим способом и не считается выполненным.
- В истории отдельно подтверждены ожидание stdin, краткая потеря Desktop Commander, квоты, неверные параметры и ошибки кода. Они уже классифицированы в [PROCESS.md](PROCESS.md).

## Что остаётся неизвестным
Внутренняя причина повторяющегося `Thinking failed` не видна из логов Mac. Нет данных о фиксированном пределе длительности сессии. Официальная справка OpenAI рекомендует новый чат при зависаниях длинного разговора, но не устанавливает таким советом диагноз этой сессии.

## Применяемые ограничения процесса
Один активный обзор одного зафиксированного diff, закрытый stdin, терминальная запись с run ID/PID/exit code, конечный wall-clock budget. Не повторять завершённые записи/деплои из-за пропавшего ответа. Не повторять известную квоту до reset. Сохранять маленький текущий handoff вместо накопления старых статусов. Не считать локальный адаптер подключённым внешним сервисом.

На этом этапе отдельно проверены свежая публичная доска и опубликованный JavaScript: файла импорта людей нет. Версия в старой вкладке пользователя не наблюдалась непосредственно. Ошибка доставки обновления интерфейса и обрывы ответа ChatGPT не объединяются в одну «проблему сети».
